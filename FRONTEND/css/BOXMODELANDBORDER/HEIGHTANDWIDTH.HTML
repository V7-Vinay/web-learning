CSS Height & Width Values

CSS height and width properties can be set using auto, fixed lengths, percentages, initial, or inherit.

Examples with Different Values

auto:
Default sizing (based on content)
length:
200px width, 150px height
%:
50% of container's width and height
initial:
Resets to default (auto)

Inherit Example

Parent Element (300px x 200px)

inherit:
Inherits parent's dimensions


Note: The height and width properties set the size of the content area (inside padding, border, and margin).
