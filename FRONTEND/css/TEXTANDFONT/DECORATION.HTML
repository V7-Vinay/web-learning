Text Decoration Properties Demo

text-decoration-line: This text is underlined using text-decoration-line: underline;

text-decoration-color: This text has a red underline using text-decoration-color: red;

text-decoration-style: This text has a wavy underline using text-decoration-style: wavy;

text-decoration-thickness: This text’s underline is 3px thick using text-decoration-thickness: 3px;

text-decoration (shorthand): This text uses a shorthand that sets an underline, dashed style, blue color, and 2px thickness.
